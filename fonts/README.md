# fonts 폴더 — 썸네일 폰트

미리캔버스 썸네일에서 쓰신 **서체 파일**을 여기에 넣으면 썸네일이 동일한 폰트로 만들어집니다.

## 넣는 법
- 제목용 폰트 파일을 `title.ttf` (또는 `.otf`)로 저장하세요.
  - 예: `fonts/title.otf`
- @bbnation·REVIEW용을 따로 쓰면 `brand.ttf` 로 저장 (없으면 title 폰트를 같이 사용).
- 파일명에 `title` / `brand` 가 들어가면 자동 인식합니다.

## 폰트 구하기
미리캔버스에서 쓴 폰트 이름을 알려주시면(예: "여기어때 잘난체", "G마켓 산스",
"Cafe24 써라운드" 등) 대부분 무료 배포라 다운로드 위치를 안내해 드릴게요.
`.ttf`/`.otf` 파일을 직접 이 폴더에 두셔도 됩니다.

폰트 파일이 없으면 macOS 기본 굵은 고딕(AppleSDGothicNeo)으로 대체됩니다.
