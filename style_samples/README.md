# style_samples 폴더

여기에 **비비 블로그의 기존 글 본문**을 텍스트 파일로 저장해주세요.
프로그램이 이 글들을 분석해 "스타일 가이드"를 만들고, 새 글을 비슷한 문체로 씁니다.

## 저장 방법

1. 네이버 블로그에서 글 하나를 열고 **본문 텍스트를 복사**합니다.
2. 이 폴더에 `글1.txt`, `글2.txt` 처럼 **한 글당 한 파일**로 저장합니다.
3. 확장자는 `.txt` 또는 `.md` 를 사용합니다.
4. 2~3개 이상 넣어두면 문체 학습이 더 정확해집니다.

## 참고

- 사진은 넣지 않아도 됩니다. **본문 글만** 있으면 됩니다.
- 파일을 추가/수정하면 프로그램이 자동으로 다시 분석합니다.
- `_profile.json` 은 분석 결과 캐시 파일이라 직접 만들 필요 없습니다.
- 샘플이 하나도 없어도 동작은 하지만, 고정 규칙(비비/뽀식이/존댓말 등)만 적용됩니다.

## 분석 대상에서 제외되는 파일

- `README.md` (이 파일)
- `_` 로 시작하는 파일 (`_profile.json` 등)
