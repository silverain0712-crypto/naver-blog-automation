## §7. v3 재진단 (2026-08-15, NAEO MCP `brief` sub=육아)

### 7-0. 성적이 올랐다 — v2 규칙이 먹혔다는 근거

| 지표 | v2 (2026-07-19) | v3 (2026-08-15, 최근 90일) |
|---|---|---|
| 분석 글 수 | 20 | 69 |
| AI 브리핑이 뜬 키워드의 글 | 3 (포착만) | 11 |
| **그중 내 글 인용** | **0 (0%)** | **2 (약 18%)** |

인용된 글: `에어프랑스 연착` / `유아식 당근양배추 라페`.
둘 다 v2에서 강제한 **"조건 → 절차 → 수치"** 형이다. 방향이 맞았으니 더 밀어붙인다.

AI가 실제로 뽑아간 문장(= 밀도 기준선):

> 유아식 당근양배추 라페는 당근·양배추를 채 썰어 절여 드레싱을 버무린 뒤 냉장 숙성해 만드는 반찬으로, 아기에게 새콤달콤한 맛을 소개하기 좋습니다.

> 무염 버전은 사과 단맛과 레몬즙으로 간을 맞추고, 생채소는 질식 위험을 줄이기 위해 소량부터 익혀서 도입하는 방식이 권장됩니다.

공통점: **대상을 문장 앞에서 정의하고, 방법과 조건을 한 문장에 다 넣었다.**

### 7-1. 정량 처방 (육아 소분류) — 세어서 확인할 것

v2까지는 "이렇게 써라"였는데, v3는 **셀 수 있는 숫자**로 바꿨다.
`modules/naeo_audit.py`가 생성 직후 자동으로 센다.

| 항목 | 기준 | v2와 충돌 시 |
|---|---|---|
| 숫자가 든 문장 비율 | 전체의 20% 이상 (표가 있으면 10%) | 신규 |
| 표 | 최소 1개 | **v2 style_rules의 "표 쓰지 말고 산문으로" 규칙 폐기** |
| 소제목 | 3~6개 | **기존 SEO 규칙 "4~8개" → 3~6개로 축소** |
| 제목 | 33자 내외 + 구체 숫자 1개 | 후보 3개 전부 숫자 포함 |
| 분량 | 1,300~1,700자 밴드 | **기존 "2,000자 이상 권장" 폐기 → 2,200자 상한** |
| 결론 위치 | 서론 직후 선요약(두괄식) | 신규 |
| 이미지 | 6장 안팎 | 신규 |

### 7-2. 문체 — NAEO 권고를 그대로 따르지 않은 부분

NAEO 플레이북은 `습니다체 6 : 해요체 4` 혼합을 권한다. **따르지 않는다.**

근거: 실제로 인용된 두 글은 전부 비비의 해요체 원문이고, 위 인용문은 AI가 요약하며 만든 문장이다.
즉 인용을 만든 건 문체가 아니라 **단정된 사실 문장**이다. 문체를 바꾸면 블로그 정체성만 잃는다.

대신 도입한 것: **뭉개는 어미 금지.**

- ✕ 가격 차이가 좀 생길 수 있어요 → ○ 세트는 29,900원이고, 육회 세트를 추가하면 39,800원이에요.
- ✕ 시간이 걸릴 수도 있어요 → ○ 남편 혼자 조립하는 데 1시간 30분 걸렸어요.

유보 어미(`~할 수 있어요`, `~인 것 같아요`)는 권유·전망·판단에만. **의료·발달·효능·안전 판단은 v2대로 계속 유보한다.**

### 7-3. 본문 골격 (인용 상위 공통)

후킹(공감+질문) + 예고 → 정의 섹션(첫 문장 정의형) → 시기·기준(월령·수치) → 확인 방법·과정
→ 대처·선택(조건-행동: "~이면 ~하세요") → 한눈에 요약 표/체크리스트 → 재요약 + 격려 + 질문 마무리

FAQ(Q&A 2~3문답)는 **절차·제도·안내형 주제일 때만**. 후기·나들이 글에 붙이면 양산 티가 난다.

### 7-4. 키워드 — 검색량이 아니라 포화도

v2의 "검색량 300~5,000 구간" 규칙은 **폐기**한다. `my_keywords`가 주는 **포화도(문서수 ÷ 월간검색)**가 실제 지표다.
포화도 1 이하면 검색량이 커도 뚫린다.

2026-08-15 기준 포화도 '여유'(0.5 미만) 황금 키워드:

| 키워드 | 월간검색 | 포화도 |
|---|---|---|
| 마리떼키즈 | 25,970 | 0.16 |
| 얼쓰빕 | 46,310 | 0.18 |
| 로토토베베 | 36,530 | 0.21 |
| 유니프랜드 | 59,280 | 0.29 |
| 산골이유식 | 39,950 | 0.34 |
| 오은영리포트 | 57,910 | 0.38 |
| 베이비본죽 | 40,200 | 0.46 |

`부가부 버터플라이2`는 v2 §5에서 최우선 글감으로 꼽았던 비교글과 겹친다 — 아직 유효.

### 7-5. AI 티 제거 (신규)

- 같은 종결어미 3문장 연속 금지.
- 섹션마다 본인 시선 1회("솔직히 ~").
- `최근·요즘·작년` 대신 정확한 연·월.
- 추상어(놀라운·중요한) 대신 숫자·고유명사.

## 1. 실측에서 나온 핵심 인사이트 (NAEO 리포트에 없는 추가 분석)

20편의 키워드별 노출 결과를 대조하면 **리뷰형은 떨어지고 정보형은 붙는다.**

노출 성공(O) 5건과 AI 브리핑 포착 3건의 정체:

| 글 | 검색량/포화도 | 성격 |
|---|---|---|
| 대한항공 와이파이 연결방법과 가격 | 3,050 / 26.8% | **절차·가격 정보** |
| 에어프랑스 와이파이 후기, 접속방법, 속도 | 320 / 34.4% | **절차·스펙 정보** |
| 몽디에스 아토크림 | 1,910 / 6.2% | 제품 리뷰 |
| 스위스 생갈렌 아기옷 쇼핑 | 20 / 0.1% | 니치 |
| 파리 루이비통 재단 박물관 | 20 / 0.8% | 니치 |

반대로 **검색량이 큰데 전부 실패(X)한 글들**:
쥬베룩볼륨 30,650 / 유모차 선풍기 22,180 / 서래마을 맛집 9,710 / 휴대용 칫솔 살균기 9,350 / 도레미곰 전집 4,460.

여기서 두 가지 결론이 나온다.

1. **AI가 인용한 글은 전부 "조건 → 절차 → 수치"가 담긴 정보형이다.** 포화도가 26~34%로 높은데도 뚫렸다. 감상 위주 후기는 검색량이 커도 안 걸린다. → 모든 리뷰 글에 **정보형 블록(스펙·가격·시간·절차 표)을 반드시 심는다.**
2. **검색량 1만 이상 대형 키워드는 아직 못 뚫는다.** 당분간 메인 키워드는 **검색량 300~5,000 · 포화도 10% 미만** 구간을 노리고, 대형 키워드는 세부 조건을 붙여 롱테일로 쪼갠다.
   - 나쁜 예: `유모차 선풍기`(22,180) → 좋은 예: `유모차 선풍기 16개월 등원용`
   - 나쁜 예: `전집 추천`(대형) → 좋은 예: `도레미곰 vs 잉글리시에그 비교`

## 2. 이번 개정에서 새로 추가되는 규칙

기존 지침에 아래 6개를 더한다. 나머지(말투, 뽀식이 호칭, 창작 금지)는 그대로 유지.
(2026-08-29 이후: 협찬 표기 자동 삽입은 폐지됐다 — 글 유형 하나로만 구분한다. prompts/post_structures.py 참고.)

### 2-1. A vs B 비교표는 선택이 아니라 필수 (비교 3/10 → 최우선)

모든 제품·장소 글에 **실제로 고민했던 대안 최소 2개**를 비교표로 넣는다.
비교 항목은 최소 3개(가격 / 크기·무게 / 아기 반응 / 사용 상황 중).

경험이 없는 제품은 **직접 쓴 것처럼 쓰지 말고 칸을 나눈다.**

| 구분 | 실제 사용 | 공식 정보만 확인 |
|---|---|---|
| 표기 | "직접 써보니" | "공식 스펙 기준" |

대안이 기억나지 않으면 지어내지 말고 `[비교 대상 필요]`로 표시한다.

### 2-2. 결과는 반드시 수치 문장으로 (결과·근거 5/10)

"좋아졌다"는 AI가 인용할 수 없다. **조건 + 수치 + 결과**가 한 문장에 다 들어가야 한다.

- ✕ 아이가 책을 더 잘 보게 되었어요.
- ○ 책을 100권 꽂았을 땐 방관했지만, 전면책장에 9권만 노출하니 매일 스스로 3권 이상 골라오기 시작했어요.

- ✕ 크림을 바르고 나서 피부가 촉촉해진 느낌이에요.
- ○ 자기 전 건조한 팔에 500원 동전만큼 덧바르니, 다음 날 아침까지 각질이 일어나지 않고 12시간 이상 촉촉함이 유지됐어요.

**작성 후 자가 점검:** 본문에서 문장 하나만 떼어내 검색 결과에 붙였을 때 그 자체로 답이 되는가? 앞 문장을 읽어야만 이해되는 문장은 AI가 인용하지 않는다.

### 2-3. 첫 문단에 독자 타겟을 명시 (독자·목적 4/10)

첫 문단 안에 **"누구를 위한 글인지"를 한 문장으로 박는다.**

> 16개월 아기와 매일 어린이집에 걸어서 등원하는데, 유모차를 계속 쓸지 트라이크로 갈아탈지 고민 중인 분께 쓰는 글이에요.

이 문장이 AI가 "이 글은 누구에게 필요한 정보인가"를 판단하는 시간을 줄여준다.

### 2-4. 실패 사례와 시행착오를 반드시 넣는다

성공담만 있는 글은 광고로 분류된다. 시행착오가 담긴 글이 **'독창적인 정보'**로 대우받는다.
"처음엔 A로 했다가 실패해서 B로 바꿨다"는 흐름을 최소 1회 넣는다.

### 2-5. 사진은 강점(8/10)이니 한 단계 더 — 정보 카드 추가

AI 브리핑이 뽑아가는 이미지는 3종이다. 글마다 최소 1장은 **정보가 담긴 이미지**로 만든다.

1. **정보가 담긴 사진** — 제품 여러 개를 나란히 놓고 비교하는 컷
2. **정리한 정보 카드** — 표를 이미지로 (예: 개월별 수면시간 표)
3. **글자 표지 카드** — 제목이 크게 박힌 썸네일

기존처럼 다양한 각도의 실물 사진은 그대로 유지하되, **표를 이미지로도 한 장 만든다.**

### 2-6. 홈피드 체류시간 장치 (한 글로 두 채널)

홈피드 추천은 **클릭(제목) × 머문 시간(본문)**으로 정해진다. 요약만 보고 이탈하지 않도록:

- 글 초반에 **"마지막에 ○○ 정리해뒀어요"**로 후반 내용을 예고
- 본문 하단에 체크리스트·정리표 등 **끝까지 봐야 할 것**을 배치
- 글 마지막을 **질문으로 마무리해 댓글 유도** (예: "여러분은 전집 어디까지 사보셨나요?")

## 3. 제목 규칙 — NAEO 권고와의 충돌 조정

NAEO는 `700만원 쓴 전집, 그냥 꽂아만 두면 0원 가치?` 같은 **궁금증형**을 권한다.
그런데 기존 지침은 `그냥 꽂아두면 0원 가치`를 **낚시성 금지 예시**로 명시하고 있다. 정면 충돌이다.

**조정안: 정보형 뼈대를 유지하되, 궁금증 요소를 딱 하나만 얹는다.**

근거는 두 가지다. 첫째, AI 브리핑에 인용되려면 제목에 **검색 가능한 명사(제품명·월령·상황)**가 있어야 하는데 순수 궁금증형은 이게 빠진다. 둘째, 통합검색 노출률 25%가 지금 더 급한 문제이고, 그건 정보형 제목이 유리하다. 홈피드 클릭률은 그다음이다.

| | 예시 |
|---|---|
| ✕ 순수 궁금증형 (검색어 없음) | 그냥 꽂아두면 0원 가치? |
| ✕ 밋밋한 정보형 (클릭 유인 없음) | 16개월 아기 전집 활용법, 잉글리시에그·도레미곰 700만원 솔직 후기 |
| ○ **정보 + 궁금증 1스푼** | 700만원 전집, 16개월 아기가 스스로 꺼내오게 만든 책장 배치법 |
| ○ **정보 + 실패 프레임** | 인스파이어 르스페이스, 14개월 아기랑 갔다가 후회한 이유(동선 사진 포함) |

즉 **"의외로 모르는", "후회한 이유", "실패한 이유"처럼 궁금증을 부르되 대상과 상황이 드러나는 표현**은 허용한다.
근거 없는 과장(`무조건`, `필수템`, `인생템`, `이것 모르면 손해`)은 기존대로 금지.

제목 후보는 계속 3개 제시하되, **3개 중 1개는 반드시 궁금증형으로** 뽑아 비교할 수 있게 한다.

## 4. 주제 정체성 관리

등록 주제는 `육아·결혼`, 실제 글은 육아템 리뷰 36% · 아기랑 이곳저곳 26% · 워킹맘 18% · 임신출산육아정보 10% · 그 외 10%(최근 50편 기준).

비육아 글(하지정맥류, 쥬베룩 등 뷰티·건강)이 섞여 있으나 **30% 미만이라 아직 안전하다.** 다만:

- 비육아 비중을 **30% 아래로 유지**한다.
- 뷰티·건강·여행 글도 **육아 맥락과 연결**한다 (산후 관리, 아기 동반 가능 여부, 워킹맘의 시간 배분 등).
- 억지 연결은 하지 않는다. 실제 관련이 있을 때만.

## §8. v4 — 네이버 메이트(육아) 4인 실측 (2026-08-22)

2026년 육아 영역 네이버 메이트로 선정된 4인의 대표글을 직접 읽고 구조를 세었다.

| 블로거 | 누적 인용 | 공백제외 | 숫자 문장 | 글 성격 |
|---|---|---|---|---|
| 도바오 | 39.2만 | 2,027자 | **7%** | 신생아 증상 → 병원 진료 기록 |
| 몽이kk | 7.4만 | 3,791자 | 6% | 이유식 거부 극복 일지 |
| 루미맘 | 6.3만 | 3,598자 | 22% | 16개월 발달 체크리스트 |
| 재재 | 6만 | **406자** | 9% | 제품 내돈내산 |

### §8-1. v3 의 전제 하나가 깨졌다

v3 은 "숫자 문장 20% 이상"과 "1,500자 이상"을 모든 글의 필수 조건으로 놨다.
그런데 20%를 넘는 건 루미맘 하나뿐이고, **누적 인용 1위 도바오는 7%**다.
재재는 **406자**로 6만 인용을 받았다.

→ 숫자 비율과 분량은 인용의 필요조건이 아니다. **글 유형마다 인용을 만드는 축이 다르다.**

| 글 유형 | 인용을 만드는 축 |
|---|---|
| 제품·비용·비교·정보 정리 | 수치 문장 (v3 규칙 그대로 20%) |
| 증상·발달·문제해결 상담 | 인과 사슬 + 전문가 소견 + 메커니즘 + 경계선 |
| 기록·일지 | 구조화된 요약 블록(`@항목: 값`) |
| 단순 제품 후기 | 제품 풀네임 + 날짜 타임라인 |

`modules/naeo_audit.py` 가 이 분기를 실제로 적용한다. 상담형으로 판정되고 **전문가 소견이
실제로 있을 때만** 숫자 목표를 8%로 낮춘다. 소견 없이 숫자만 없는 글은 그냥 미달이다.

### §8-2. 도바오(39.2만)에게서 가져온 것 — 상담형의 골격

증상 발견 → 1차 진료(소아과→신경외과, X-ray) → **이상 없음** → 본인이 원인 재특정
(뒤통수가 아니라 왼쪽 턱) → 2차 확인(영유아검진) → 정상 판정 → 추가 리서치로 메커니즘 설명
→ **경계선 체크리스트** → 결론.

- **내가 틀렸던 지점을 밝힌다.** 이 문장이 같은 걸 검색한 사람의 질문과 맞물린다.
- **전문가 소견을 직접 옮긴다.** "신경외과에서 엑스레이를 찍었고 결과는 이상 없음이었어요."
- **메커니즘 한 문장.** "턱관절 딸깍 소리는 관절 안 디스크가 움직였다 제자리로 돌아오며 나요."
- **경계선 불릿 2~4개.** 괜찮다고만 쓴 글은 답변으로 쓰이지 못한다.

### §8-3. 루미맘(6.3만) — 섹션의 완성형

`소제목 + 한 줄 요약 + ✔ 불릿 4~5개 + 우리 아이 실제 사례`. 6개 영역(걷기/놀이/생활습관/
언어/인지/사회성)에 불릿 26개. 이 묶음이 AI 가 통째로 떼어가는 단위다.

도입 3줄 리드도 여기서 가져왔다 — 인사보다 **먼저** [주제 정의] + [누가 궁금해하는지] +
[다룰 항목 나열]을 박는다. 서론이 아니라 답변 요약이라고 생각하고 쓴다.

한계도 있다. 루미맘 글은 근거가 전부 "~라고 해요"다. 출처를 붙이면 더 강해진다.

### §8-4. 몽이kk(7.4만) — 기록형의 요약 블록

글 끝에 `@New 재료 / @스케쥴 / @이유식 양 / @우리아기의 이유식 스타일은?` 형태로 압축.
표가 어색한 일지형 글에서 표를 대신한다. 시도마다 번호를 붙이고(1. 자기주도식_원물 스틱)
실패도 그대로 남긴다.

### §8-5. 재재(6만) — 406자가 6만 인용을 받은 이유

- 제목에 **브랜드 + 정식 제품 풀네임**을 줄이지 않고 그대로 썼다.
- 본문이 **날짜 타임라인**이다: 6/9 구매 → 6/11 도착 → 8/1 여름휴가 사용.

제품을 특정할 수 있는 이름과 실사용 시점이 명확하면, 짧아도 인용된다.

### §8-6. 제목 — 4인 공통

- **월령·나이를 맨 앞에.** 4인 중 3인이 그렇게 썼다(검색어 입력 순서와 같다).
- 세부 키워드가 많으면 괄호로 나열: `7개월 중기 이유식 거부 기록(스푼피딩 거부, 자기주도식, 밥솥이유식)`
