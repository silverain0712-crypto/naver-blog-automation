# 비비 블로그 네이버 상위노출 플레이북

> 2026-07 실측 연구. 최근 한 달 발행 글의 핵심 육아니치 7개 키워드에 대해
> 모바일 네이버 블로그탭 상위노출 글(키워드당 4~15개)을 실제 수집·구조분석한 결과.
> AI탭(CUE: AI 검색)은 curl 수집 불가 → 원리 기반으로 정리.
> 이 문서의 규칙은 `modules/post_generator.py` 의 SEO 블록에 코드로 반영되어 있음.

## 0. 수집 방법 (재현용)
모바일 UA만 접근 가능(PC탭 차단).
```
UA="Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1"
curl -s -A "$UA" "https://m.search.naver.com/search.naver?where=m_blog&query=<URL인코딩>" \
  | grep -oE "blog\.naver\.com/[a-zA-Z0-9_-]+/[0-9]+" | awk '!seen[$0]++' | head -10
curl -s -A "$UA" "https://m.blog.naver.com/{ID}/{글번호}"   # 개별 글 본문(se- 클래스)
```
주의: 블로그탭 상위 슬롯 상당수가 인플루언서 홈/광고 카드라 직링크 블로그는 키워드당 소수만 추출됨.

## 1. 상위노출 공통 패턴 (7개 키워드 종합)

| 지표 | 상위노출 글 실측 | 비비 현재(중앙값) | 판정 |
|---|---|---|---|
| 글자수(공백제외) | 제품리뷰 1,500~2,200 / 정보·비교글 2,000~3,600 | 1,484 (정보·장소글 1,000~1,200) | ⚠️ 정보·장소글 얇음 |
| 사진 | 리뷰 18~56 / 정보 3~20 (안전권 15~20+) | 14 (정보글 7) | ⚠️ 정보·장소글 부족 |
| 표(se-table) | 비교·스펙·요금·시간에 자주. 강한 상위노출 신호 | 거의 0 | ❌ 최대 갭 |
| 소제목 | 4~8개, 번호형/질문형, se-quotation | 8개 | ✅ (형식만 개선) |
| 영상 | 상위글 약 절반 포함(체류 신호) | 드묾 | ⚠️ |
| 제목 | 세부차별KW 앞배치 + 후킹어, 25~35자 | 25자 | 🔸 세부KW 보강 |

### 콘텐츠 유형별 두 갈래
- **제품 리뷰**: 사진 20장+ · 스펙/성분/인증 · 비교표 · 1,500~2,200자
- **정보·비교·장소**: 표/소제목 집중 · 방법론·수치·로컬정보 · 2,000자+ (권위·최신성이 특히 중요)

## 2. 상위노출 비법 (요소별)

1. **제목 공식** = `[세부 차별 키워드] + 핵심 키워드 + [후킹어]`
   - 세부차별KW: 브랜드·모델명 / 용량·형태(12L·오븐형·집게형·문어발형) / 개월수(15개월) / 연도(2026) / 실용질문(물 나오는 시간·주차)
   - 후킹어: 후기·추천·비교·내돈내산·총정리·완벽정리
   - 관련 KW 2개는 나란히 병기 (아기 칫솔+유아 칫솔 / 보관함+정리함)
2. **도입부** = 첫 2~3문장에서 독자 상황 특정. (a)페인포인트 공감 (b)결론 선제(GEO) (c)계절·날씨 훅
3. **표를 적극 사용** — 제품 스펙/비교, 장소 운영시간·요금은 표로. (현재 최대 약점)
4. **정보 밀도** = 상위노출·체류의 핵심. 제품(스펙·수치·성분·인증), 육아(개월수·기간·단계 방법명), 장소(위치·시간·주차·요금·가는법 5요소)
5. **미디어량** — 사진 15~20장+, 영상 1개 이상 권장(체류 신호), 장소글은 네이버 지도 첨부(진정성)
6. **최신성/시즌** — 최근 1~2주 발행이 강한 신호. 시즌 키워드는 성수기 2~4주 전 선점. 제목에 연도(2026)
7. **권위/신뢰** — 전문가 타이틀·내돈내산·직접사용·성분/인증. 정보글은 전문가·서적 인용이 장기 상위의 열쇠

## 3. 키워드 선정법
- 단일 대형 키워드(레드오션) 대신 **롱테일 조합**: 세부수식어 + 핵심어
  - 제품: `브랜드/모델명 + 용량/형태 + 일반KW + 후기/비교`
  - 육아정보: `개월수 + 상황(낮잠거부·방거부) + 방법/성공후기`
  - 장소: `연도 + 지역 + 신설시설명 + 실용정보(시간·주차·요금)`
- **정보형 키워드로 리뷰 레드오션 우회**: "○○ 사용법/청소/세균/비교"는 협찬 리뷰 경쟁을 피하는 블루오션
- **신설·틈새 시설 선점**: 예) '반포 물방울쉼터/쿨링포그'는 전용글이 거의 없어 지금이 선점 최적기
- **연관 검색어 20개+**를 본문에 자연스럽게(스터핑 금지), 동의어·연관어로 변주

## 4. 네이버 AI검색(CUE:) 최적화 원리
AI탭은 특정 글 스크랩이 불가하나, AI 검색이 인용·요약에 채택하는 글의 공통 특성:
- **질문형 소제목**으로 Q&A 구조를 만든다(AI가 답변 단위로 추출하기 쉬움)
- **명확한 사실·수치**를 단정적으로 서술(불소 1,000ppm, 운영 09~18시, 6개입 등)
- **결론/요약 문단을 앞 또는 뒤에** 배치(GEO — Generative Engine Optimization)
- **출처·근거 명시**(보건복지부 매뉴얼, FSC 인증 등)로 신뢰도 확보
- 표·리스트로 **구조화된 정보** 제공 → AI가 그대로 인용
※ 이 원리는 `GEO_STRUCTURE` 로 이미 시스템에 일부 반영됨. 위 항목을 강화 반영.

## 5. 비비 우선 개선 액션 (효과순)
1. **정보·장소 글 표 추가** + **글자수 2,000자+** (최대 갭 — 반포 물방울쉼터 983자 → 로컬정보 5요소 표로 재작성)
2. **정보·장소 글 사진 15~20장+**로 보강
3. **제목에 세부 차별 키워드 앞배치**(연도·개월수·모델명·실용질문) + 관련 KW 병기
4. **소제목 질문형/번호형**으로, 각 소제목에 정보 덩어리 1개
5. **영상 1개** 습관화(체류 신호)
